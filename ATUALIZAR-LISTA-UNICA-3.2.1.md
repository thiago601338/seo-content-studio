# Atualizacao 3.2.1 - Lista unica

1. Substitua os arquivos do repositorio pelos desta versao.
2. Confirme `version: 3.2.1` em `package.json`.
3. No Netlify, use **Clear cache and deploy site**.
4. Abra o sistema e use **Ctrl + F5**.

Nao ha SQL novo nem variaveis novas.

## Mudanca principal

A tela Gerar artigos agora possui apenas uma lista: a tabela. Para inserir varios itens, clique em **Adicionar em lote**, cole uma informacao por linha e use **Adicionar a tabela**.
